## 次のステップ: `iwato`（磐戸町奇譚）

2Dドット絵・見下ろし型ホラーアドベンチャー。Godot 4.7。
タイル 32px、基準解像度 640×360、色数 64、2Dライト + ノーマルマップ。
**キャラクターは対象外**（背景・タイルセット・UI・アイコンのみ）。

### 1. フィールド定義（F01〜F16）

16フィールドの一覧を作る。置き場所は `projects/iwato/requirements/`。

決める必要があること:

- 各フィールドの識別子と名称、および相互の接続関係
- フィールドごとの時間帯・天候の別（同一フィールドの差分を何種類持つか）
- 屋内／屋外の別（タイルセットの共用範囲が変わる）
- 1フィールドあたりの画面数（640×360 何枚分か）

**これが素材の総数を決める。** 先にここを固めないと、後続の見積もりが立たない。

### 2. 素材要件

「何を何枚作るか」を確定する。置き場所は `projects/iwato/requirements/`。
カテゴリは `tilesets` `objects` `overhead` `ui` `icons` の5つ。

決める必要があること:

- カテゴリごとの必要点数
- タイルセットの構成（オートタイルの有無、必要なタイル種別）
- UI 要素の一覧（ダイアログ枠、メニュー、カーソル等）
- アイコンの一覧と寸法（32px 基準でよいか、16px も要るか）
- ノーマルマップを付ける対象の範囲（全素材か、背景とタイルのみか）

### 3. パレット確定

置き場所は `projects/iwato/palettes/`。確定したら `project.yaml` の
`palette.file` にパスを書く。

決める必要があること:

- 48〜64色のどこに落とすか（`project.yaml` の `max_colors` は現在 **64**）
- 明度の段数と、2Dライトの暗部で潰れない下限
- ホラー表現で使う色域の方針（低彩度の寒色中心か、特定色をアクセントに置くか）
- パレットのファイル形式（`.gpl` を想定しているが未確定）

**色数を 64 から変える場合は `project.yaml` の `palette.max_colors` を必ず更新する。**
`validate_assets.py` の判定基準がこの値だけを見るため。

### 4. スタイルガイドとベースプロンプト

`projects/iwato/style/` の2ファイルを埋める。雛形の見出しだけがある状態。
パレットとフィールド定義が固まってから書くほうが手戻りが少ない。
