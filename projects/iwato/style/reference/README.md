2026-09-04、F06 パイロットで `/map-objects` から得たもの。**投影が
アイソメトリックであるため素材としては採用しない**が、以下の点で

| 項目 | 内容 |
| --- | --- |
| 光源と本体の分離 | 本体が `indigo` 51%、発光パネルが `vending` 14% + `green` 21%。**「光源だけが彩度を持つ」が成立している** |

| 透明度 | アルファは 0 と 255 のみ |

**新しい素材の質を判断するときは、これと比べること。**
「日本の物として識別できるか」「光源だけが彩度を持っているか」の2点が基準。
